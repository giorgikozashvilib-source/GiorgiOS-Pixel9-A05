££ Project Overview
GiorgiOS Pixel 9 Edition is a custom ROM research and documentation project tailored for the Samsung Galaxy A05.

£££ Key Features & Goals
- Pixel-inspired UI: Standardized Pixel 9 aesthetics and system overlays.
- Dynamic Partitioning: Configured for standard ARM64 super layout.
- Safety First: Built purely for structure verification and non-destructive analysis. No stock firmware is altered or flashed without explicit verification.
