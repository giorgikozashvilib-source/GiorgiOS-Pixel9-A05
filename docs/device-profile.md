# Device Profile: Samsung Galaxy A05 (a05m)

## Hardware Specifications
- **Model Number**: SM-A055F, SM-A055M
- **Codename**: `a05m`
- **SoC**: MediaTek Helio G85 (MT6769V/CZ)
- **CPU**: Octa-core (2x2.0 GHz Cortex-A75 & 6x1.8 GHz Cortex-A55)
- **GPU**: Mali-G52 MC2
- **Architecture**: `arm64-v8a`
- **Storage Type**: eMMC 5.1
- **Partition Structure**: Dynamic Partitions (`super` partition layout)
- **Original OS**: Android 13 (One UI 5.1), upgradable to Android 15.
